INTERNET  
INICIO

  • Los navegadores son herramientas esenciales para acceder a internet, pero no todos persiguen los mismos objetivos. Aparte de los navegadores gráficos que usa la mayoría de la gente, existen opciones ligeras, navegadores basados en texto y muchas otras alternativas, cada una con sus ventajas y desventajas.

  • Un navegador es un software diseñado con el propósito de ofrecer acceso a internet, recupera páginas de los servidores y te las muestra de forma que puedas verlas e interactuar con ellas. Entre los más populares se encuentran Chrome, Firefox, Opera, Safari y Edge. Como dato curioso hay que mencionar que la introducción de los navegadores web en la década de 1990 desempeñó un papel fundamental en la adopción masiva de internet.

  • Los navegadores solicitan información de Internet o de servidores privados y la transforman en páginas accesibles. Cuando escribes una dirección o haces clic en un enlace, el navegador envía una solicitud a un servidor utilizando HTTP o HTTPS. Luego, el servidor responde con el contenido solicitado y que el navegador ha procesado para que puedas verlo con facilidad.

  • El motor de renderizado de un navegador convierte los datos de los servidores en páginas web legibles, lee código como HTML, CSS, JavaScript y XML. Estas instrucciones son las que indican cómo debe verse una página, desde detalles como la fuente del texto hasta la ubicación de las imágenes. Los navegadores transforman estos miles de líneas de código en una página que puedes leer y con la que también puedes interactuar.

  • No obstante, no todos los navegadores utilizan el mismo motor de renderizado y esto puede influir en la velocidad, el uso de recursos y el modo en que las páginas web se muestran. Por ejemplo, Chrome, Opera y Edge utilizan Blink, Firefox usa Gecko y Safari funciona con WebKit.

  • Los navegadores modernos también pueden ampliarse mediante extensiones, que son pequeños complementos para añadir funcionalidades. Las extensiones pueden bloquear anuncios, ofrecer herramientas de organización, modificar la apariencia visual de una página web, completar contraseñas y mucho más. La mayoría están desarrolladas con lenguajes web estándar y pueden instalarse de forma segura desde fuentes oficiales como Chrome Web Store o Firefox Add-ons.
